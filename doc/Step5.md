# Step 5 – 载荷 / 结构估算（Loads & Structural Reasoning）

---

## 1. 步骤定义与成功标准

### 1.1 定义

本步骤关注：**在没有完整 FEA 求解的前提下，对机械结构进行载荷与强度的快速估算与推理**，为设计决策提供即时反馈。典型任务包括：

- 根据需求和工况，**定义载荷工况**：
  - 集中载荷 / 均布载荷 / 扭矩 / 内压 / 温度载荷等；
  - 边界条件（简支、固支、铰支等）；
- 对常见结构形态进行 **快速强度 / 刚度估算**：
  - 梁挠度估算、弯曲应力、扭转角、接触应力大致量级；
- 对估算结果进行 **安全性判断**：
  - 与材料屈服 / 疲劳强度对比；
  - 安全系数是否满足要求。

### 1.2 成功标准

一个 Agent 在本步骤中表现“合格”，典型标准包括：

1. **物理一致性**
   - 所采用的力学模型与假设合理（如小挠度假设、Euler-Bernoulli 梁理论适用条件）；
   - 不出现明显违反物理规律的结论（负应力、方向完全错误等）。

2. **量级正确性**
   - 对典型梁 / 轴 / 板结构，在给定荷载和几何下，估算应力 / 挠度的数量级与标准解析解或 FEA 结果一致；
   - 例如相对误差控制在 20%–30% 以内，用于“早期设计筛选”。

3. **清晰的假设与边界条件**
   - 能在输出中明确说明：
     - 把哪一段结构视为简支梁 / 固支梁；
     - 忽略了哪些高阶效应（剪切变形、应力集中等）；
   - 方便工程师判断估算是否适用。

4. **可与 FEA 结果对照**
   - 在有条件时，结构估算结果与有限元求解结果在趋势和主控区域上保持一致。

## 2. 具体案例示例

**案例：悬臂梁挠度与应力的快速估算**

- 几何参数：
  - 悬臂梁长度 \(L = 0.5 \, \text{m}\)
  - 宽度 \(b = 0.04 \, \text{m}\)
  - 厚度 \(h = 0.01 \, \text{m}\)
- 材料：
  - 结构钢，弹性模量 \(E = 210 \, \text{GPa}\)
  - 屈服强度 \(\sigma_y \approx 250 \, \text{MPa}\)
- 载荷：
  - 梁自由端承受竖直向下集中力 \(F = 200 \, \text{N}\)
- 问题：
  1. 估算梁根部最大弯曲应力；
  2. 估算自由端挠度；
  3. 判断安全系数（静强度）。

**解析估算（示意）**：

- 截面惯性矩：
  \[
  I = \frac{b h^3}{12}
  \]
- 根部弯矩：
  \[
  M = F L
  \]
- 最大弯曲正应力：
  \[
  \sigma_{\max} = \frac{M c}{I}, \quad c = \frac{h}{2}
  \]
- 自由端挠度（Euler-Bernoulli 悬臂梁公式）：
  \[
  \delta_{\max} = \frac{F L^3}{3 E I}
  \]
- 安全系数：
  \[
  \text{SF} = \frac{\sigma_y}{\sigma_{\max}}
  \]

**Agent 的理想回答**：

- 正确写出上述公式；
- 代入数值，给出近似结果；
- 判断 \(\text{SF} > 2\) 是否满足设计要求；
- 说明采用的是线弹性、小挠度梁弯曲理论。

## 3. 专业模型 / 软件（面向结构估算与验证）

> 这一环节目前没有“专门为载荷估算训练的 LLM”，更多是 **经典 CAE 工具 + 通用 LLM** 组合使用。下面列的是你可以实际用来做“快速验证”和“训练标签”的软件 / 环境。

### 3.1 SymPy（符号计算 / 解析解求解）

- **是否开源**：是（BSD 许可）  
- **链接**：https://www.sympy.org  
- **主要功能**：
  - Python 下的符号数学库，可用于推导和求解梁、轴、板的解析公式；
  - 对于标准结构力学例题，可用 SymPy 自动推导弯矩图 / 挠度函数。
- **输入**：
  - 符号变量（例如 \(E, I, L, x, F\)）；
  - 平衡方程、边界条件。
- **输出**：
  - 闭式表达式（形如 \(\delta(x) = \ldots\)）；
  - 可以进一步 numeric subs 得到数值估算。

> 在你的 Agent 流程中，SymPy 可以作为 “解析解 oracle” 对简单结构进行验证，用于评估 LLM 的估算是否合理。

---

### 3.2 FreeCAD FEM 工作台 + CalculiX（开源 FEA 管线）

- **FreeCAD FEM Workbench**
  - **是否开源**：是（随 FreeCAD 一同发布，LGPL）  
  - **主要功能**：
    - 支持为 3D 模型设置材料属性、约束和载荷；
    - 调用外部求解器（如 CalculiX）进行线性静力、模态等分析；
    - 提供图形化的应力、位移云图显示。  
- **CalculiX**
  - **是否开源**：是（GPL）  
  - **链接**：
    - 官方站点（文档、源码）：https://www.calculix.de  
  - **主要功能**：
    - 类似 Abaqus 输入格式的开源有限元求解器；
    - 支持 3D 实体、壳、梁等多种单元，线性/非线性分析。  

**输入 / 输出**

- 输入：
  - FreeCAD 模型（几何）；
  - 材料（E, ν）、载荷（力、压力）、边界条件；
  - 网格参数。
- 输出：
  - CalculiX 求解结果（位移、应力、反力等），在 FreeCAD 中以云图展示。

> 你可以将 FreeCAD + CalculiX 组合视作 “参考真值生成器”，用于校验 LLM 的载荷估算结果，或者生成训练标签。

---

### 3.3 其他开源 FEA 选项（可选）

- **Code_Aster / Salome-Meca**
  - **是否开源**：是（GPL/LGPL）  
  - **功能**：面向土木与机械结构的高级 FEA，适合更复杂非线性问题；
- **Elmer FEM**
  - **是否开源**：是（开放源代码，政府支持）  
  - **功能**：多物理场 FEA（结构、热、流体、电磁）。

> 对 Step 5 的初版 benchmark，你通常不需要这么重的工具；FreeCAD+CalculiX 即可作为主参考。

## 4. 评测环境：如何评估“载荷 / 结构估算”性能

### 4.1 基于教材例题 / 解析解的评测

1. **构建题库**
   - 选取经典《材料力学》《结构力学》例题，包括：
     - 简支梁 / 悬臂梁的各种载荷组合；
     - 轴扭转、薄壁管扭转；
     - 简单框架结构。
   - 每道题都应具有：
     - 完整的几何 & 载荷说明；
     - 标准解析解（应力 / 挠度 / 转角）。

2. **评测流程**
   - 将题目以自然语言形式输入 LLM / Agent；
   - 模型输出解析式或直接数值；
   - 使用 SymPy 或手写解析解进行数值比对。

3. **指标**
   - 数值误差（如相对误差均值 / 中位数）；
   - 是否采用了正确公式（可用 AST 分析或人工审查）；
   - 对假设条件的说明是否恰当（人工评分）。

---

### 4.2 基于简化几何 + FEA 参考解的评测

1. **构造参数化零件**
   - 用 CadQuery / FreeCAD 定义一组典型结构（梁、轴、板、简支框架等）；
   - 参数包括：尺寸、材料、载荷位置和大小。

2. **自动生成 FEA 真值**
   - 对每组参数化几何：
     - FreeCAD FEM + CalculiX 自动网格划分；
     - 求得最大主应力、关键点挠度等指标；
   - 保存为结构化标签（JSON）。

3. **Agent 评测**
   - 不让 Agent 调 FEA，只提供几何与载荷参数（文本或结构化）；
   - 要求 Agent 估算应力/位移，并说明所用理论；
   - 将估算与 FEA 真值对比。

4. **指标**
   - 数值误差（例如 RMS 相对误差）；
   - 对高危工况（应力接近屈服）的判定是否敏感（ROC 曲线）；
   - 估算用时（相对 FEA 的加速比，更多用于工程意义）。

## 5. 若要训练 Agent：可用的开源 / 可构建数据集

目前尚没有“标准化的载荷 / 结构估算 LLM 训练集”，但你可以组合以下资源：

### 5.1 教材/题库类结构力学数据（自建）

- 来源：
  - 结构力学 / 材料力学教材中的例题、习题（需人工录入或通过 OCR + 校验）；
  - 开源的工程力学题库（如部分教学网站提供的练习题，需注意版权）。
- 数据形式：
  - 输入：自然语言描述（题干）；
  - 输出：解析式 + 数值结果 + 题目参数；
- 处理方式：
  - 用 SymPy 建立解析求解脚本，自动生成多组参数的题目与解答；
  - 构成规模化的“结构估算”预训练数据。

> 好处：结构明确、物理可靠，非常适合做“链式推理 + 公式推导”训练。

---

### 5.2 参数化几何 + FEA 标签（自建）

- 使用 CadQuery / FreeCAD + CalculiX 构造：
  - 多组随机参数（梁长、截面尺寸、材料、载荷等）；
  - 自动生成对应的 FEA 真值；
- 构成数据对：
  - 输入：几何与载荷参数（可用 JSON + 简单自然语言描述）；
  - 输出：关键应力/位移的数值，甚至是简化“经验公式”形式。

**示例数据条目（示意）**：

```json
{
  "geometry": {
    "type": "cantilever_beam_rect",
    "L_m": 0.5,
    "b_m": 0.04,
    "h_m": 0.01
  },
  "material": {
    "E_GPa": 210,
    "sigma_y_MPa": 250
  },
  "load": {
    "type": "point",
    "F_N": 200,
    "position": "free_end"
  },
  "fea_result": {
    "sigma_max_MPa": 85.3,
    "delta_max_mm": 2.1
  }
}
```
- Agent 训练任务可以是：“根据上面的输入，估算 sigma_max 和 delta_max”。

---

### 5.3 通用工程题 + LLM 自动增强（合成数据）

- 利用强基线模型（如 GPT-4 / DeepSeek-R1），在严格 prompt 下生成大量结构力学问答，并建立自检（self-check）或与解析解对比机制。
- 这些数据可用于预训练，但由于存在潜在错误，建议：
  - 仅在早期阶段用作“粗预训练”；
  - 核心评测和 finetune 仍以解析解 / FEA 真值为基准。

## 6. 若要评测 Agent：可以公开或自建的评测集

目前没有一个被广泛接受的 “LLM 结构估算 benchmark”，可按如下方式构建：

### 6.1 “解析解题库”评测集

- 内容：
  - 从教材中选取 50–200 个经典结构力学题目，覆盖不同边界条件与受力形式。
- 形式：
  - 提供统一的自然语言描述；
  - 存储标准解析解脚本（SymPy）；
  - 可公开（去除教材版权后自写题目），成为领域通用评测集。

### 6.2 “CAD+FEA 真值”评测集

- 内容：
  - 一组参数化零件（梁、支架、轴等），每个配有数十种载荷/支撑组合，每个组合都有 FEA 结果作为真值。
- 形式：
  - 开源 FreeCAD 模型 + CalculiX 输入文件；
  - JSON 标注：应力、位移、危险点位置等。
- 使用方法：
  - 供任何人将自己的 LLM / Agent 接入评测脚本，对照真值计算误差。

## 7. 小结：Step 5 在整个链路中的角色

Step 5 位于：

- 上承 Step 2/3/4（零件几何 / 装配 / 运动学）；
- 下接 Step 6/7（Tool-use FEA / 设计优化）。

**实际工程意义：**

- 作为“预筛选”环节，在大规模配置空间中快速筛掉显然不安全或极度过设计的方案；
- 当 LLM/Agent 能稳定地给出物理合理的载荷估算时，可以显著减少 FEA 调用次数，从而大幅提升整个自动设计 pipeline 的效率。

**从资源角度看：**

- 虽然目前没有专门的 “结构估算 LLM benchmark”，但你可以通过：
  - 教材级解析解题库；
  - 小规模 CAD+FEA pipeline；
  - SymPy 解析解辅助；

来自建一套相对严谨又可扩展的 Step 5 评估环境。
