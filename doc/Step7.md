# Step 7 – 设计优化 / 多目标优化（Design Optimization & Multi-Objective Trade-off）

## 1. 步骤定义与成功标准

### 1.1 定义
本步骤旨在让 Agent 能够执行系统性的机械设计优化，包括：
- 单目标优化（如最小质量、最小顺应度、最大刚度）
- 多目标优化（生成 Pareto 前沿）
- 拓扑优化（TopOpt）
- 多学科设计优化（MDO：结构 + 热 + 气动等）

要求 Agent 能够基于 Step 6 的 CAD/FEA Tool-Server，在迭代过程中：
1. 修改设计变量  
2. 触发 CAD 生成或修改  
3. 触发 FEA 求解  
4. 根据结果进行下一步优化  

### 1.2 成功标准
- 明确目标函数与约束表达  
- 能驱动 CAD/FEA 工具链形成闭环迭代  
- 能生成合理的 Pareto 解  
- 在基准优化问题上结果可与已有框架对齐

## 2. 具体案例示例

### 悬臂支架的质量–刚度双目标优化

**设计变量：**
- 厚度 t
- 加强筋参数（高度/数量/位置）

**目标：**
1. 最小化质量 m
2. 最小化自由端挠度 δ

**约束：**
- 最大 von Mises ≤ 180 MPa
- 最小壁厚 ≥ 3 mm

**Agent 流程：**
1. 从自然语言抽取目标、约束和变量范围  
2. 调用 CAD Tool 生成几何  
3. 调用 FEA Tool 求解应力与位移  
4. 用 NSGA-II / BO / RL 进行更新  
5. 生成 Pareto 前沿

## 3. 专业模型 / 软件（优先开源）

### 3.1 OpenMDAO（多学科设计优化框架）
- **开源**：Apache 2.0  
- **地址**：https://github.com/OpenMDAO/OpenMDAO  
- 由 NASA 开发  
- 可将 CAD/FEA 结果作为 Component  
- 自动求导、多目标、多约束、并行优化

**输入：**
- 设计变量、边界条件、目标函数

**输出：**
- 优化后的变量  
- 收敛过程、目标函数曲线  

---

### 3.2 TopOpt_in_PETSc（大型开源拓扑优化）
- **开源**：MIT  
- **地址**：https://github.com/topopt/TopOpt_in_PETSc  
- 面向 3D 结构的拓扑优化  
- 使用 PETSc 并行求解  
- 支持 SIMP、最小顺应度优化

**输入：**
- 网格、载荷、边界、体积分数、惩罚系数

**输出：**
- 单元密度场（最终拓扑结构）

---

### 3.3 Anton（基于 Blender 的生成式拓扑优化框架）
- **开源**：MIT  
- **地址**：https://github.com/senthurayyappan/anton  
- Blender 内置拓扑优化工具  
- 自动生成结构形状，可导出 STL

---

### 3.4 Cadrille（CAD 任务上的在线 RL 训练范式）
- **论文公开**  
- 多模态输入（图像/点云/文本）生成 CAD 程序  
- 使用 Online RL（GRPO）提高建模质量  
- 提供可借鉴的 RL 训练范式，用于设计优化奖励
